The two rules, and why they fight each other

WCAG 1.4.3 (Contrast Minimum) asks the link to be readable: 4.5:1 against its background for normal text. WCAG 1.4.1 (Use of Color) asks the link to be findable: it must not be identified by color alone, so either the link differs from the surrounding body text by 3:1, or it carries a non-color cue — an underline, bold weight, an icon, a border (technique G183). The two rules pull in opposite directions: a light link stands out from dark body text but fades into a white background; a dark link is readable on white but sits too close to dark body text to be noticed. Most real link colors fail one of the two. That is not a bug in the test — it is why browsers underline links by default, and why removing the underline is a WCAG decision, not a styling one.

How to fix a failing link

  1. Underline it. The cheapest, most robust fix — and the one browsers ship by default. An underline (or bold, icon, or border) satisfies WCAG 1.4.1 with no color requirement at all. If your design system removed underlines for looks, this tool is showing you what that cost.
  2. Darken the body text. With a blue-600 link, moving body text from #1F2937 to #111827 (2.84 → 3.43) crosses the line. Do not lighten the body text — that direction makes the link-vs-body ratio smaller.
  3. Check the visited state too. Visited purple #551A8B fails against black body text (1.91:1) even when your unvisited blue passes. Run the check with the visited color as well.
  4. Do not trust "it looks blue enough". #0000EE looks unmistakably like a link to a sighted reader — and measures 2.23:1 against black text. The number is the test, and the test exists for readers who cannot see the blue.

How the math works

All three ratios use the same WCAG 2.1 formula as the main contrast checker: relative luminance from linearized sRGB (weights 0.2126 red, 0.7152 green, 0.0722 blue), then (L1 + 0.05) / (L2 + 0.05). Thresholds are inclusive: exactly 4.50:1 passes AA, exactly 3.00:1 passes the G183 body-text test. The overall verdict requires link-vs-background ≥ 4.5:1 and (link-vs-body ≥ 3:1 or an underline). FAQ

Isn't 4.5:1 enough for a link?

No. 4.5:1 is only the link-versus-background test (WCAG 1.4.3). WCAG 1.4.1 separately requires the link to be distinguishable from the surrounding body text — a 3:1 color difference, or a non-color cue such as an underline. A link can pass 4.5:1 and still be invisible as a link to a color-blind reader.

Does an underline really fix a failing link?

Yes. Technique G183 lists underlining (and other non-color cues such as bold, an icon, or a border) as a valid way to distinguish links from surrounding text, with no color-difference requirement at all. That is exactly why browsers underline links by default — and why removing the underline creates a WCAG problem most teams never measure.

Why does the classic blue link fail the test?

The web's original link blue, #0000EE, measures 9.40:1 against white — AAA — but only 2.23:1 against black body text, below the 3:1 line. Even against pure black it cannot pass, so a classic blue link with no underline fails WCAG 1.4.1. The visited-link purple #551A8B is worse at 1.91:1 against black. Both need underlines (or a different link color).

Can I pass both rules with color alone?

Sometimes, but the window is narrow. The link's luminance must sit in a band: dark enough for 4.5:1 against the background, light enough for 3:1 against the body text. For example, blue-600 #2563EB passes both when the body text is #111827 or darker (3.43:1), but fails when the body is #1F2937 (2.84:1). Darkening the link helps the background test and hurts the body test; lightening the body text makes the body test worse, not better.

Do dark-mode links have the same problem?

Yes, mirrored. On a #121212 background with #E5E7EB body text, every common light link color fails the 3:1 link-vs-body test — #93C5FD is 1.46:1, #60A5FA 2.05:1, #FBBF24 1.35:1 — even though all of them pass 4.5:1 against the background. Dark-mode links need underlines too, or a much darker body text.
